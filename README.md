# BUET CSE Coursework

Four years of computer science coursework from [Bangladesh University of Engineering and Technology (BUET)](https://www.buet.ac.bd), organized by level and term. Covers everything from foundational algorithms to kernel hacking, compilers, graphics, and machine learning.

## Notable Implementations

- **Compiler (CSE310):** Full four-stage pipeline — lexical analysis (Flex) through 8086 assembly code generation.
- **xv6 Kernel (CSE314):** Lottery-based CPU scheduler and virtual memory/paging added to the MIT xv6 teaching OS.
- **Ray Tracer (CSE410):** Recursive ray tracer with reflections, shadows, and Phong shading; separate rasterization pipeline for comparison.
- **CNN from Scratch (CSE472):** Forward and backward passes, ReLU/softmax, fully connected layers — no deep learning frameworks.
- **Cryptography (CSE406):** AES and RSA implemented in Python; paired with hands-on buffer overflow labs (SEED Labs).
- **Processor in Logisim (CSE306):** Datapath with ALU, register file, and data memory wired from basic logic gates.
